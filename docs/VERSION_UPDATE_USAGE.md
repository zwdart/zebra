# 版本更新功能使用说明

## 功能概述

Zebra SSH 支持自动检测新版本并下载更新，覆盖 Windows、Linux、macOS、Android、iOS 全平台。

## 功能特性

- **自动检测**：启动时自动检查是否有新版本（静默，不打扰用户）
- **手动检测**：在设置页面可随时手动检查更新
- **强制更新**：管理员可设置强制更新，用户必须更新后才能继续使用
- **平台适配**：根据平台自动选择合适的下载和安装方式
- **多类型支持**：支持文件下载和外部链接两种更新方式
- **错误容错**：网络异常或 API 不可用时，不影响正常使用

---

## 使用方法

### 1. 自动检查更新

启动应用后，系统会在后台自动检查是否有新版本。如果有新版本，会弹出更新提示。

**自动检查的特点：**
- 不阻塞应用启动
- 网络异常时静默失败
- 有新版本时弹窗提示

### 2. 手动检查更新

1. 打开应用，进入 **设置** 页面
2. 找到 **检查更新** 选项并点击
3. 系统会显示检查状态
4. 如果有新版本，会显示版本信息和更新日志

### 3. 下载和安装更新

#### 文件类型更新

##### 桌面平台（Windows / Linux / macOS）

1. 在更新弹窗中点击 **下载**
2. 显示下载进度
3. 下载完成后点击 **安装**
4. 系统会自动启动安装程序

##### 移动平台（Android / iOS）

1. 在更新弹窗中点击 **更新**
2. 自动跳转到应用商店
3. 在商店中完成更新

#### URL类型更新

当管理员设置为外部链接类型时：
1. 在更新弹窗中点击 **打开链接**
2. 系统会跳转到浏览器打开指定链接
3. 用户在浏览器中完成下载或操作

### 4. 强制更新

当管理员设置强制更新时：
- 弹窗无法关闭（没有跳过按钮）
- 必须完成更新才能继续使用
- 会显示醒目的提示信息

## 界面说明

### 更新弹窗

| 状态 | 显示内容 |
|------|----------|
| 检查中 | 旋转动画 + "正在检查更新..." |
| 有新版本（文件） | 版本号、发布日期、文件大小、更新日志、下载/安装按钮 |
| 有新版本（URL） | 版本号、发布日期、更新日志、打开链接按钮 |
| 无新版本 | 对勾图标 + "当前已是最新版本" |
| 下载中 | 进度条 + 已下载/总大小 |
| 下载完成 | 完成图标 + "安装"按钮 |
| 检查失败 | 错误图标 + 错误信息 + 重试按钮 |

### 设置页面

在设置页面的"关于"分组下，新增"检查更新"选项：
- 未检查时显示正常图标
- 有新版本时显示红色更新图标，并显示新版本号
- 检查中时显示加载动画

## 平台差异

| 平台 | 检查更新 | 文件类型 | URL类型 |
|------|----------|----------|---------|
| Windows | 支持 | 下载 .exe → 运行安装 | 跳转浏览器 |
| Linux | 支持 | 下载可执行文件 → chmod +x | 跳转浏览器 |
| macOS | 支持 | 下载 .dmg → open | 跳转浏览器 |
| Android | 支持 | 下载 .apk 或跳转商店 | 跳转浏览器 |
| iOS | 支持 | 跳转 App Store | 跳转浏览器 |

## 版本号说明

### 版本号 (version)

格式：`主版本.次版本.修订号`，如 `1.2.0`

### 版本码 (version_code)

用于版本比较的整数值，**越大表示版本越新**。

**两种设置方式：**
1. **手动设置**：管理员上传时指定
2. **自动使用ID**：留空则使用数据库自增ID（后上传的记录ID更大）

**示例：**
| 版本号 | 版本码 | 说明 |
|--------|--------|------|
| 1.0.0 | 1 | 手动设置 |
| 1.1.0 | 2 | 手动设置 |
| 1.2.0 | 3 | 使用自增ID |

## 常见问题

### Q: 检查更新失败怎么办？

A: 检查更新失败不影响正常使用。可能的原因：
- 网络连接异常
- API 服务器维护中

可以稍后在设置页面手动重试。

### Q: 下载速度很慢？

A: 下载速度取决于网络状况和服务器带宽。建议在网络良好的环境下更新。

### Q: 强制更新后能跳过吗？

A: 强制更新无法跳过，必须完成更新才能继续使用。这是为了确保用户使用安全、稳定的版本。

### Q: 更新后数据会丢失吗？

A: 不会。更新只替换应用程序文件，用户数据（连接配置、数据库等）不会受影响。

### Q: 如何查看当前版本？

A: 进入设置 → 关于页面，可以看到当前版本号。

### Q: URL类型更新是什么？

A: URL类型更新是管理员设置的外部链接，点击后会跳转到浏览器打开该链接，适用于需要跳转到官网或第三方下载页面的场景。

## 管理员操作

### 发布新版本（文件类型）

1. 编译新版本的应用
2. 登录管理后台 `http://服务器IP:8686/admin`
3. 点击「+ 上传新版本」
4. 类型选择「上传文件」
5. 选择平台和安装包文件
6. 填写版本号、更新日志等信息
7. 点击「上传」

### 添加版本（URL类型）

1. 登录管理后台 `http://服务器IP:8686/admin`
2. 点击「+ 上传新版本」
3. 类型选择「外部链接」
4. 输入下载链接和版本信息
5. 点击「上传」

### 设置强制更新

在编辑版本时：
- 将「强制更新」设置为「是」

### 查看健康状态

```
GET /api/health
```

响应示例：
```json
{
  "status": "ok",
  "service": "zebra-update-api",
  "version": "1.0.0",
  "uptime_secs": 3600,
  "started_at": "2026-07-13 10:00:00",
  "pid": 12345
}
```

### 版本列表筛选

管理后台支持按平台筛选版本：
- 全部：显示所有平台的版本
- Windows / Linux / macOS / Android / iOS：只显示对应平台的版本

每个平台会自动标识最新版本（版本码最大的记录显示 [最新] 标识）。
