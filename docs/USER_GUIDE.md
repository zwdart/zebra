# Zebra SSH 使用说明

Zebra SSH 是一款跨平台 SSH 客户端，支持终端连接、文件管理、系统监控等功能。

## 安装

从官网或应用商店下载对应平台版本:

| 平台 | 文件 |
|------|------|
| Windows | `zebra.exe` (自解压可执行文件) |
| macOS | `Zebra.app` (应用包) |
| Linux | `zebra` (自解压可执行文件) |
| Android | `app-release.apk` |
| iOS | App Store 搜索 "Zebra SSH" |

## 快速开始

### 1. 添加连接

1. 打开应用，点击右下角 **+** 按钮
2. 填写连接信息:
   - **名称**: 自定义标识 (如 "我的服务器")
   - **主机**: 服务器 IP 或域名
   - **端口**: 默认 22
   - **用户名**: SSH 登录用户名
3. 选择认证方式:
   - **密码认证**: 输入密码
   - **密钥认证**: 选择私钥文件，可选输入密钥口令
4. 可选填写备注
5. 点击 **保存**

### 2. 连接服务器

在连接列表中点击 **连接** 按钮，等待连接建立后自动进入终端界面。

### 3. 基本操作

**终端**:
- 输入命令并按回车执行
- 支持常用快捷键 (Ctrl+C, Ctrl+V 等)
- 多标签: 点击顶部 + 号可打开新终端会话

**SFTP 文件管理**:
- 点击连接卡片上的 **文件** 按钮进入
- 浏览远程目录结构
- 点击文件可下载
- 拖拽文件到窗口可上传 (桌面端)

**系统监控**:
- 点击连接卡片上的 **监控** 按钮
- 查看 CPU、内存、磁盘使用率
- 查看和管理进程

## 功能详解

### 连接管理

- **搜索**: 在首页顶部搜索框输入关键词筛选连接
- **编辑**: 点击连接卡片上的编辑图标修改信息
- **删除**: 点击删除图标并确认
- **排序**: 最近使用的连接排在前面

### 终端功能

- 多会话: 同时打开多个终端标签
- 自适应: 终端窗口大小自动适配
- 复制粘贴: 支持系统剪贴板

### SFTP 文件管理

- 目录浏览: 点击文件夹进入子目录
- 返回上级: 点击 ".." 或返回按钮
- 文件下载: 点击文件名下载到本地
- 文件上传: 桌面端支持拖拽上传

### 系统监控

- 实时数据: CPU/内存/磁盘使用率
- 进程列表: 查看运行中的进程
- 进程管理: 终止不需要的进程

### 设置

- **主题**: 切换亮色/暗色模式
- **语言**: 切换中文/英文
- **更新**: 检查新版本

### 日记

- 本地存储的私人日记
- 支持标题、内容、心情标记
- 支持搜索

### 博客

- 在线阅读技术博客
- 支持 Markdown 渲染

### 发现

- 推荐工具和资源
- 支持按分类筛选
- 支持搜索

### 反馈

### 关于

- 查看应用版本信息

### 常用命令

- 内置常用 Linux 命令参考
- 支持搜索命令

## 更新

应用启动时自动检查更新:

- **有更新**: 弹窗提示，可选择立即更新或跳过
- **强制更新**: 无法跳过，必须更新后才能使用
- **跳过更新**: 跳过后 7 天内不再提示

## 常见问题

### 连接失败

**症状**: 提示 "Cannot connect to host:port"

**解决**:
1. 检查网络是否正常
2. 确认服务器 IP 和端口正确
3. 确认服务器 SSH 服务已启动
4. 检查防火墙是否放行端口

### 认证失败

**症状**: 提示 "Authentication failed"

**解决**:
1. 检查用户名和密码是否正确
2. 如使用密钥认证，确认密钥文件有效
3. 确认服务器允许该用户 SSH 登录

### 文件上传失败

**症状**: SFTP 上传文件无响应或报错

**解决**:
1. 检查远程目录写入权限
2. 确认磁盘空间充足
3. 尝试上传较小文件测试

### 终端显示异常

**症状**: 终端文字错乱或显示不全

**解决**:
1. 调整终端窗口大小触发刷新
2. 输入 `reset` 命令重置终端

### 更新下载失败

**症状**: 更新弹窗提示下载失败

**解决**:
1. 检查网络连接
2. 稍后重试
3. 手动从官网下载最新版本

## 平台特定说明

### Windows

- 安装包双击运行即可
- 支持拖拽上传文件
- 系统托盘最小化

### macOS

- 双击 Zebra.app 运行
- 首次运行可能需要右键选择 "打开"

### Linux

- 运行自解压可执行文件: `chmod +x zebra && ./zebra`
- 安装到系统: 使用 `build_linux.sh` 的安装功能

### Android

- 需要存储权限 (文件上传下载)
- 支持后台运行

### iOS

- 首次连接需确认信任
